# Tasks

This directory contains epic files for AIDD task management.

- Active epics are stored as `[epic-name]-epic.md`
- Completed epics are moved to `archive/YYYY-MM-DD-[epic-name].md`

See [COPILOT-QUICKSTART.md](../COPILOT-QUICKSTART.md) for how to create and manage epics with the `@aidd` agent.
