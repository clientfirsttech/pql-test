# Adopt PQL.Assert 0.9.0 Epic

**Status**: ✅ COMPLETED (2026-11-02)
**Goal**: Map ODCS `frequency` to the new native `Tbl.LastRefreshShouldBeWithinHours`, closing the gap our own request opened.

## Overview

`frequency` currently has no real PQL.Assert function behind it — just an inline `INFO.PARTITIONS()` expression wrapped in the generic `ShouldBeLessOrEqual` — so 0.8 users get a less diagnostic failure message than PQL.Assert's other checks give. 0.9.0 ships the function pql-test asked for ([docs/pql-assert-freshness-request.md](../docs/pql-assert-freshness-request.md)), so adopting it gives `frequency` the same `TABLE NOT FOUND` / `NEVER REFRESHED` / `DIRECTQUERY (no refresh)` diagnostics the library's other checks already have.
